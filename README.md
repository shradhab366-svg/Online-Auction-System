
# 🛒 Online Auction System

## 📌 Project Description

This is a simple **Online Auction System** developed using HTML, CSS, and JavaScript.
It allows users to register, place bids, and view the winner after the auction ends.

---

## 🚀 Features

* 👤 User Registration
* 📦 Product Display
* 💰 Live Bidding System
* ⏳ Countdown Timer
* 🏆 Automatic Winner Declaration

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
